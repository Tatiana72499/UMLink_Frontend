# Calidad frontend

- Mantener TypeScript estricto y componentes pequeños.
- Accesibilidad: HTML semántico, foco visible, botones con nombre accesible y contraste suficiente.
- Manejar carga, vacío y error en toda pantalla que consuma API.
- Mantener DTOs alineados con el backend; cambios de contrato se coordinan con el backend.
- Añadir pruebas para servicios, rutas y componentes relevantes.
- Ejecutar `npm run build` y `npm test` antes de marcar una tarea como terminada.
