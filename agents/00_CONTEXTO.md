# Contexto frontend

UMLink permite diseñar diagramas de clases colaborativamente. Este frontend consumirá el backend local en `http://localhost:8080/api` y más adelante se conectará al WebSocket `/ws`.

Prioridad actual: establecer una base Angular limpia para autenticación, proyectos y diagramas. La autenticación JWT fue autorizada explícitamente para vincular cada proyecto con su creador. No implementar aún IA, voz, XML o canvas complejo sin una tarea explícita.
